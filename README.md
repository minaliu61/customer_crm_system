# 🏢 客户信息管理系统 (CRM System)

一个基于 Spring Boot 和 Thymeleaf 开发的多角色企业级客户关系管理简易系统。系统实现了不同权限人员对企业客户、产品及订单数据的精细化日常管理。

## 🛠️ 技术栈
- **后端**：Java 8+、Spring Boot、MyBatis
- **数据库**：MySQL
- **前端**：Thymeleaf 模板引擎、HTML5、CSS3、原生 JavaScript
- **项目管理**：Maven

## ✨ 核心功能与角色说明
系统包含三种登录身份，针对不同角色分配不同权限：
1. **管理员 (Admin)**：
   - 具备最高权限，可管理管理员账号、销售人员账号。
   - 管理客户信息、产品类别、产品信息（增删改查）。
   - 查看所有订单记录。
2. **销售人员 (Sales)**：
   - 维护个人信息及修改密码。
   - 管理自己名下的客户信息、产品信息。
   - 查看所有订单记录。
3. **客户 (Customer)**：
   - 仅拥有查看和修改个人信息的权限。
   - 查看自己的历史订单信息。
- **通用功能**：登录验证、右上角个人信息查看、密码修改、安全退出登录。
